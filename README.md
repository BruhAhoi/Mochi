# 🍡 Mochi

A real-time messaging web application inspired by Messenger, built with React, Node.js, and TypeScript.

🔗 **Live Demo**: [mochi-coral-three.vercel.app](https://mochi-coral-three.vercel.app)

---

## ✨ Features

- 💬 Real-time messaging between users
- 👤 User authentication (register / login)
- 📋 Conversation & contact list management
- 🟢 Online/offline status indicators
- 📱 Responsive UI across devices

---

## 🛠 Tech Stack

### Frontend
| Technology | Description |
|---|---|
| React + Vite | UI framework & build tool |
| TypeScript | Type-safe development |
| CSS | Styling |

### Backend
| Technology | Description |
|---|---|
| Node.js + Express | REST API server |
| TypeScript | Type-safe development |
| WebSocket / Socket.io | Real-time communication |

## 🚀 Getting Started

### Prerequisites
- Node.js >= 18
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/BruhAhoi/Mochi.git
cd Mochi
```

#### Frontend
```bash
cd frontend
npm install
npm run dev
```

#### Backend
```bash
cd backend
npm install
npm run dev
```
